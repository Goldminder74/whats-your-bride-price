WYBP Recovery privacy notice

Prepared 12 October 2026. This notice describes the dedicated operational recovery tool, not the game's full customer privacy notice.

Responsible operator

Ayodele Ayeni, trading as Classes for Culture, is responsible for this tool. Contact team@classesforculture.com about privacy or access. This is an internal operator tool, not a customer purchase or sign-in service.

Google data and permissions

The authorised operator connects a dedicated Google OAuth application using only https://www.googleapis.com/auth/drive.file and offline access. The tool uses an access token, renewed with a securely stored refresh token, to manage files created by or explicitly selected for this application in its restricted recovery folder.

It reads file metadata such as IDs, names and parent-folder membership and downloads the corresponding encrypted bytes for checksum and recovery verification. It creates encrypted backup and authority records and deletes expired operational files. It does not request whole-Drive, Gmail, contacts or calendar access, or access to unrelated files.

Contents and purpose

Operational archives can contain game, ownership, wallet, order, accounting, support, hold, closure and deletion-authority records needed to recover the application safely. Such records may include personal data already held by the application. The purpose is operational continuity, verified recovery and preservation of accounting and deletion/hold decisions, not advertising, profiling or marketing.

Backup content is encrypted before upload. Google receives encrypted file content and the metadata required to store it. Runtime credentials and encryption keys must be stored separately from public files and source control. They are not included in browser bundles, backup files, alert messages or this notice.

Access and providers

Google Drive provides independent file storage; Cloudflare provides the operational runtime and database when configured. Access is limited to the authorised operator and securely configured runtime. The tool does not intentionally create public sharing links or sell Google user data. An independent human recovery custodian has not been confirmed.

Google-account data obtained through this tool is used only for these disclosed recovery functions, consistently with the Google API Services User Data Policy, including applicable Limited Use requirements.

Retention and deletion

The approved operational-backup window is 30 days. Reading or retrying a backup does not renew its original retention window. Expired recovery boundaries must not restore access. Provider file IDs are retained until deletion has been acknowledged so a lost response can be retried safely.

This operational window does not replace longer approved retention for financial records, active legal holds or necessary accounting dependencies in the source system. Recovery must preserve deletion, minimisation, closure and hold authority. It must not reopen a closed wallet or silently restore deleted access.

Scheduled cleanup is not active yet; live delivery, independent key retrieval, monitoring and bounded deletion capacity must be verified before production operation. Completed hosted deletion and continuous recovery have not yet been verified.

Disconnecting Google access

The operator can revoke this application's access in Google Account connections. Revocation stops future authorised API operations; it does not itself delete existing Drive files or application records. Existing backup deletion and credential removal must be handled through the approved operational procedure.

Contact the operator for access, correction, deletion or other data-protection questions. These operator terms do not restrict applicable privacy rights.
