WYBP Recovery

WYBP Recovery is a private operational backup and recovery tool for Classes for Culture, operated by Ayodele Ayeni, a UK sole trader.

It is used by the authorised operator to preserve encrypted application backups and recovery records in a dedicated private Google Drive folder. It is not a customer sign-in service, a payment service or the public game.

Google Drive access

The tool requests only Google's drive.file permission, with offline access for unattended operation. This allows it to create, read, check and delete files created by or explicitly selected for this application. It does not request access to your entire Drive, Gmail, contacts or calendar.

The operator selects or creates a dedicated restricted backup folder. The tool uploads encrypted recovery files, checks downloads against cryptographic checksums and remembers their Drive file IDs so interrupted delivery can resume without intentionally creating duplicate backups.

Who can use it?

This application is intended only for the authorised Classes for Culture operator. Customers do not connect their Google accounts. Backup files are not made public or shared through public links.

Current status

Runtime installation and live verification are pending. Continuous backup, monitoring and scheduled cleanup are not yet active. Local synthetic checks do not establish hosted recovery guarantees.
