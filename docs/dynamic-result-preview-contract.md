# Permanent result and dynamic preview contract

Date: 24 August 2026

`dynamic_results` is disabled by default and cannot be enabled by a query parameter. Ordinary production builds require both approved durable result storage and generated-media storage. Authorised local fixtures require `WYBP_REVIEW_BUILD=true`, `WYBP_REVIEW_RESULT_FIXTURES=true` and the feature flag at build time; fixture data is absent from ordinary production output.

Eligible URLs use `/result/{48 lowercase hexadecimal characters}`. Server resolution requires explicit public visibility, active lifecycle and no elapsed expiry. Every unavailable state returns `This result is no longer available.` with generic metadata. The public identity is always `A challenger` because the existing optional name field is not separate proof of public-name consent.

The deterministic preview is PNG, exactly 1200 by 630 pixels and has a hard maximum of 1,000,000 bytes, with a preferred target below 500,000 bytes. It uses proper deterministic deflate compression through the Worker-compatible Web Compression API and adds no package dependency. It contains one approved regional motif and palette, an approved avatar medallion, authoritative score/total, approved tier title or mastery label, quiz/Classes for Culture branding and `A playful culture score, never a measure of human worth.` The opaque public result slug contributes an imperceptible 192-bit pixel salt so two visually identical public results retain distinct immutable media records without exposing an internal ID. No renderer input accepts a remote image URL, SVG, font URL, private photo or browser score.

Object keys use `generated/{edition}/{YYYY}/{MM}/{sha256}-vog1.png`. The public delivery path accepts only the result slug and matching content hash, rechecks the safe result projection, returns `image/png`, an SHA-256 ETag and immutable versioned caching, and supports conditional requests. Unavailable media returns a neutral 404 with `no-store`. Unpublishing revokes metadata and deletes generated bytes at the origin.

`/og-v2.png` is only the temporary fallback for unavailable states, missing generated assets or generation/storage failure. It is not the normal preview for an eligible public result. It currently does not contain the permanent safeguard; this limitation must remain explicit until a separately approved fallback-artwork replacement.

No GET, HEAD, metadata or crawler request publishes a result, prepares a new asset, creates an attempt or challenge acceptance, increments a human-start counter or emits an analytics event. Preview generation occurs only during the explicit, same-origin, owner-authorised publication mutation. That POST body contains the existing 32-character raw anonymous-session credential as `anonymousSessionCredential`, never the stored subject hash. The server derives `SHA-256("wybp-anonymous-subject-v1\0" + credential)`, compares it in constant time with the authoritative `quiz_attempts.anonymous_subject_hash`, and requires the associated completed attempt and its ownership window to remain unexpired. Missing, malformed, copied stored hashes, mismatched credentials and credentials replayed after expiry receive the same neutral unavailable response. An identical authorised retry inside the valid ownership window remains idempotent and does not create a second result or asset.
